# Прошивка IDometer 2.2 — как залить в прибор

Прошивка проверена сборкой на ядре ESP32 3.3.12 (последнее стабильное на конец
октября 2026). Залить её можно так же, как вы прошивали прибор раньше: через
Arduino IDE и USB-кабель.

## 1. Подготовка Arduino IDE (один раз)

1. **Ядро ESP32.** «Инструменты → Плата → Менеджер плат», найти **esp32 by Espressif
   Systems** и обновить до последней версии 3.x.
2. **Библиотеки.** «Инструменты → Управлять библиотеками»:
   - **Adafruit ST7735 and ST7789 Library** — установить; на вопрос про
     зависимости ответить «Установить все».
   - **SparkFun MAX3010x Pulse and Proximity Sensor Library** — скорее всего уже
     стоит со старой прошивки; если нет, установить.

   Библиотеки TFT_eSPI и PubSubClient новой прошивке не нужны, удалять их
   не обязательно.

## 2. Wi-Fi

Начиная с прошивки 2.1 имя сети и пароль в прошивку вписывать не нужно.
Прибор помнит до 5 сетей и сам подключается к той, что рядом.

**Добавить сеть с телефона (удобнее всего на новом месте):**
1. Включите прибор, держа нажатой **правую кнопку** (или просто подождите:
   если знакомой сети нет 30 секунд, прибор сам перейдёт в этот режим).
2. На экране прибора появится «WiFi SETUP».
3. На телефоне подключитесь к Wi-Fi сети **IDometer-setup** (без пароля).
4. Страница настройки откроется сама. Если нет — откройте в браузере
   телефона адрес **192.168.4.1**.
5. Выберите сеть, введите пароль, нажмите «Сохранить и подключиться».
   Через несколько секунд на приборе появится «WiFi: OK».

Сеть должна быть **2,4 ГГц** и та же, к которой подключён компьютер.

**Через монитор порта Arduino IDE** (скорость 115200), команды:
`wifi` — добавить сеть (прибор спросит имя и пароль), `list` — сохранённые
сети, `forget 2` — забыть сеть №2, `setup` — включить режим настройки,
`status` — состояние прибора.

Если вы уже вписали свою сеть в config.h — можно оставить: при первом запуске
прибор сохранит её сам.

## 3. Заливка

1. Подключите прибор USB-кабелем.
2. «Инструменты → Плата → esp32 → **ESP32 Dev Module**» (подойдёт и «LilyGo T-Display»).
3. «Инструменты → Порт» — выберите COM-порт прибора.
4. Нажмите «Загрузить» (стрелка вправо).

Если загрузка обрывается с ошибкой «Failed to connect»: нажмите и держите
**левую кнопку** на плате (рядом с USB), снова нажмите «Загрузить», и отпустите
кнопку, когда пойдут проценты.

## 4. Что показывает экран прибора

| Строка | Значение |
|---|---|
| WiFi: OK / WiFi: ... | подключён к сети (ниже — её имя и адрес прибора) или ищет знакомую |
| WiFi SETUP | режим настройки сети с телефона (см. пункт 2) |
| PC: linked / PC: searching | программа на компьютере найдена или нет |
| Finger: OK / none | палец на датчике пульса |
| GSR: число | сырой сигнал кожи (должен меняться, когда электроды надеты) |
| SD, Bat, sent | резервная запись на карту, батарея, сколько пакетов отправлено |

**Правая кнопка** гасит и включает экран — чтобы он не отвлекал клиента.

## 5. Запуск с компьютером

Запустите `3_receiver_real_device.bat`. Если Windows спросит про доступ Python
к сети — разрешите для **частных** сетей. Через несколько секунд на приборе
появится «PC: linked», а в программе — графики.

**Если «PC: searching» не исчезает**, почти всегда причина в брандмауэре Windows:
сеть отмечена как «Общедоступная». Исправить: «Параметры → Сеть и Интернет →
(ваше подключение) → Тип сетевого профиля → **Частная**». Другой способ —
вписать IP компьютера в `RECEIVER_IP` в config.h.

## 6. Если что-то пошло не так

Откройте в Arduino IDE «Монитор порта» на скорости 115200, отправьте команду
`status` и пришлите ответ.

## Что изменилось по сравнению со старой прошивкой

- Нет NTP, часовых поясов и MQTT — время сводит компьютер, с точностью до миллисекунд.
- Выборка по аппаратному таймеру: PPG 100 Гц, кожа 20 Гц, без двухсекундного
  усреднения, которое размывало ответы.
- Пульс не считается в приборе: на компьютер идёт сырая пульсовая волна.
- Прибор не зависает без сети или без датчика: работает с тем, что есть.
- Резервная запись всех данных на SD-карту, если она вставлена
  (файлы `/idm/rec_NNNN.bin`).
- Кожа в программе пока в **относительных единицах** (0–100, больше = выше
  проводимость). Микросименсы появятся после калибровки на резисторах.

С версии 2.2 сообщения прибора в мониторе порта и страница настройки Wi-Fi
на телефоне — на английском.
