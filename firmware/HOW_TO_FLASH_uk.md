# Як залити прошивку IDOmeter 2.2

Перевірено збиранням на ядрі ESP32 Arduino 3.3.12.

## 1. Arduino IDE (один раз)

1. **Менеджер плат**: встановіть або оновіть **esp32 by Espressif Systems** до
   останньої версії 3.x.
2. **Менеджер бібліотек**: встановіть **Adafruit ST7735 and ST7789 Library**
   (на запитання про залежності — «Install all») і **SparkFun MAX3010x Pulse and
   Proximity Sensor Library**.

## 2. Заливання

1. Відкрийте `IDometer_fw/IDometer_fw.ino`.
2. Плата: **ESP32 Dev Module** (або «LilyGo T-Display»); виберіть COM-порт.
3. Натисніть «Завантажити». Якщо з'являється «Failed to connect», затисніть
   ліву кнопку (біля USB) на початку завантаження.

## 3. Wi-Fi без перекомпіляції

Прилад пам'ятає до 5 мереж і сам під'єднується до тієї, що поруч.

**З телефона:** увімкніть прилад, тримаючи **праву кнопку** (або зачекайте 30 с
без знайомої мережі). На екрані з'явиться «WiFi SETUP». Під'єднайте телефон до
Wi-Fi **IDometer-setup**; сторінка налаштування відкриється сама (або відкрийте
**192.168.4.1**). Виберіть мережу, введіть пароль, збережіть.

**Через монітор порту** (115200): `wifi`, `list`, `forget N`, `setup`, `status`, `help`.

Мережа має бути 2,4 ГГц і тією самою, до якої під'єднано комп'ютер.

## 4. Екран

| Рядок | Значення |
|---|---|
| WiFi: OK / WiFi: ... | під'єднано (нижче назва мережі та IP приладу) / пошук |
| WiFi SETUP | режим налаштування з телефона |
| PC: linked / searching | програму на комп'ютері знайдено / ще ні |
| Finger: OK / none | палець на датчику пульсу |
| GSR: число | сирий сигнал шкіри |
| SD, Bat/USB, sent | резервний запис, живлення, надіслано пакетів |

**Права кнопка** вимикає й вмикає екран, щоб він не відволікав клієнта.

## 5. Якщо «PC: searching» не зникає

Майже завжди причина в брандмауері Windows: зробіть профіль мережі **Приватним**
(Параметри → Мережа та Інтернет → ваше під'єднання) і дозвольте `python.exe` у
брандмауері (Win+R → `firewall.cpl` → «Дозволити взаємодію з програмою…» →
«Дозволити іншу програму…»). Інший спосіб — вписати IP комп'ютера в `RECEIVER_IP`
у `config.h`.
